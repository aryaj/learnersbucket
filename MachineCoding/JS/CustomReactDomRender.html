Custom ReactDom.Render

This example demonstrates how to implement a custom ReactDOM.render function that can render React-like components to the DOM.

Problem Summary

  • Implement a custom render function that takes a React element and a container.
  • Support rendering basic HTML elements like div, span, h1, etc.
  • Handle nested elements and children.
  • Support text nodes as children.
  • Replace existing content in the container.

How It Works: Step-by-Step Approach

  1. Element Structure: A React-like element is a plain JavaScript object with type (tag name), props (attributes), and children (nested elements or text).
  2. Recursive Rendering: The render function processes each element recursively. It creates a DOM element, applies props as attributes, then renders children.
  3. Props Handling: Loop through props using Object.entries() and set them as properties on the DOM element.
  4. Children Processing: Children can be either strings (text nodes) or element objects. Handle both cases separately.
  5. Assembly: Append each rendered child to the parent element, then append the root to the container.

Example Structure

const element = {
  type: "div",
  props: { id: "app", className: "container" },
  children: [
    { type: "h1", props: {}, children: ["Hello"] },
    { type: "p", props: {}, children: ["This is a paragraph"] }
  ]
};

Implementation Strategy

function render(element, container) {
  // 1. Base case: if element is a string, create a text node
  if (typeof element === 'string') {
    return document.createTextNode(element);
  }

  // 2. Create the DOM element with the given type (e.g., 'div', 'h1')
  const domElement = document.createElement(element.type);

  // 3. Apply props as attributes to the element
  if (element.props) {
    Object.entries(element.props).forEach(([key, value]) => {
      domElement[key] = value;
    });
  }

  // 4. Recursively render children
  if (element.children) {
    element.children.forEach((child) => {
      const renderedChild = render(child, container);
      domElement.appendChild(renderedChild);
    });
  }

  return domElement;
}

// Usage:
render(element, document.getElementById('app'));
