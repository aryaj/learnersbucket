Filter Nested Object

This problem focuses on filtering deeply nested objects/arrays based on a predicate while preserving the original shape as needed.

Problem Summary

  • Accept a nested object/array and a filter condition.
  • Traverse recursively through all levels.
  • Keep only matching values/nodes.
  • Preserve original structure for retained branches.
  • Handle empty branches after filtering.

Solution Approach

// In-place DFS approach (mutates original object):
      // 1) Iterate each key in current object.
      // 2) Read value = obj[key].
      // 3) If value is nested object, recurse first (go deep).
      // 4) If value is primitive, apply predicate and delete when false.
      // 5) After recursion returns, delete key if nested object became empty.
      // 6) Continue until all levels are processed.

Implementation Notes

// API shape:
      // deepFilter(obj, predicate)
      //
      // - obj: nested object that will be mutated in-place
      // - predicate: function for primitive values (returns true/false)
      // - behavior: removes non-matching primitives + prunes empty nested objects
