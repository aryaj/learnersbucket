Fetch with Timeout — Documentation

Purpose: Perform a fetch request that will be aborted if it does not settle within a given timeout.

Function: fetchWithTimeout(url, timeoutLimit)

  • url — request URL (string).
  • timeoutLimit — timeout in milliseconds (number). If the fetch does not finish within this time, the request is aborted.

Behavior notes:

  • The function returns the fetch Promise so callers can handle response parsing and errors.
  • On timeout, the underlying AbortController aborts the request — fetch will reject with an AbortError.
  • The timeout timer is always cleared when the fetch settles (success or failure).

Usage example

const p = fetchWithTimeout('/api/data', 5000);
  p.then(r => r.json())
   .then(data => console.log(data))
   .catch(err => {
     if (err.name === 'AbortError') console.log('Request timed out');
     else console.error(err);
   });
