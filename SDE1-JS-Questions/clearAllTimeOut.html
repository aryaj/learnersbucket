Clear All Timeouts

This page documents a timer manager that tracks timeout IDs and clears them all at once.

Implementation

const MY_TIMERS = {
  timerIds: [],
  setTimeout(fn, delay) {
    const timerId = setTimeout(fn, delay);
    this.timerIds.push(timerId);
    return timerId;
  },
  clearAllTimeout() {
    while (this.timerIds.length) {
      clearTimeout(this.timerIds.pop());
    }
  },
};
