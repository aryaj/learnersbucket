Polyfill - Promise.all

This example implements a simplified version of Promise.all. It accepts an array of promises, waits until all of them resolve, and returns a new promise with results in the original order.

How it works

The polyfill creates a result array and tracks completed promises. Each promise is attached with .then and .catch. When all promises have resolved, the polyfill resolves with the collected values. If any promise rejects, the polyfill rejects immediately.

Implementation

function PromiseAllPolyfill(arr) {
  const result = [];
  let completed = 0;

  return new Promise((resolve, reject) => {
    arr.forEach((promise, index) => {
      promise
        .then((value) => {
          result[index] = value;
          completed += 1;
          if (completed === arr.length) {
            resolve(result);
          }
        })
        .catch(reject);
    });
  });
}
