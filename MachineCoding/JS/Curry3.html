Curry3

Convert a normal function that expects four arguments into a curried function. The curried version should accept arguments in groups across multiple calls and invoke the original function only when enough values have been collected.

Problem Statement

Implement a generic curry(fn) helper that wraps a function and returns a new function. If the total number of collected arguments is less than the original function's arity, return another function; otherwise, call the original function with the collected values and return the result. 

function sum(a, b, c, d) {
  return a + b + c + d;
}

const curriedSum = curry(sum);

curriedSum(1, 2, 3, 4); // 10
curriedSum(1)(2, 3)(4); // 10
curriedSum(1)(2)(3)(4); // 10

Approach (Step By Step)

  • Read the function arity: fn.length tells us how many arguments the original function expects.
  • Collect arguments in a closure: the inner helper remembers the arguments passed so far.
  • Base case: if the count reaches the required arity, call fn(...args) and return the value.
  • Continuation case: if not enough arguments are present, return a new function that keeps accumulating more arguments.
  • Merge arguments across calls: each new function call passes the existing arguments and the newly received arguments into the same helper.

Closure and Dry Run

The helper function closes over the arguments array from the current currying chain. That closure lets the function remember previously received values even when the caller invokes it again with more arguments in a new call. 

curriedSum(1)(2, 3)(4)

1. First call: helper(1)
   args = [1], fn.length = 4, still short
   return temp

2. Second call: temp(2, 3)
   helper(...[1], ...[2, 3]) => helper(1, 2, 3)
   args = [1, 2, 3], still short
   return temp

3. Third call: temp(4)
   helper(...[1, 2, 3], ...[4]) => helper(1, 2, 3, 4)
   args.length === fn.length
   return sum(1, 2, 3, 4) => 10

Complexity

  • Time complexity is O(n), where n is the number of arguments collected before the function is finally invoked.
  • Space complexity is O(n) for the captured argument array held by the closure until evaluation completes.
