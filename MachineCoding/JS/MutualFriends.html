Mutual Friends

Recursively collect all reachable friends from a given person in a friend mapping graph.

Problem Summary

  • Input: mapping object and one starting person.
  • Each person maps to a list of direct friends.
  • Collect direct + indirect friends recursively.
  • Backtracking merges each child result into parent result.
  • Base case: person has no entry or empty friend list.

Approach (Step By Step)

// STEP 1: Read friendList = mapping[person].
// STEP 2: If no friendList or empty, return [] (base case).
// STEP 3: Create finalList with direct friends [...friendList].
// STEP 4: For each direct friend, recurse and get child list.
// STEP 5: Backtrack: merge child list into current finalList.
// STEP 6: Return finalList for this recursion frame.
//
// Important:
// - Each recursion call has its own local finalList.
// - Backtracking happens right after child call returns.
// - Parent frame continues from the next line in the loop.

Dry Run (a)

// mapping:
// a -> [b, c]
// b -> [d, g]
// d -> [p, q]
//
// mutualFriends(mapping, "a")
// finalList(a) = [b, c]
//   recurse(b)
//     finalList(b) = [d, g]
//       recurse(d) => [p, q]
//       backtrack merge => [d, g, p, q]
//       recurse(g) => []
//     return [d, g, p, q]
//   backtrack merge into a => [b, c, d, g, p, q]
//   recurse(c) => []
// return [b, c, d, g, p, q]

Complexity

  • Time: O(V + E) in graph terms for reachable nodes/edges.
  • Space: O(H) recursion depth + output storage.
  • Note: Cycles are not handled in current version.
