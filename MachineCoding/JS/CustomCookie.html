Custom Cookie

This example demonstrates how a custom property can behave like a cookie by using Object.defineProperty with a setter and getter. It is a simplified learning demo, not a full browser-cookie implementation.

Problem Summary

  • Parse a cookie-like string such as name=ajay;max-age=4.
  • Store the value in an in-memory map.
  • Use a getter/setter to control how values are assigned and read.
  • Support expiry using the max-age option.

Implementation Idea

Object.defineProperty(document, 'myCookie', {
  configurable: true,
  set(value) {
    const { key, value: cookieValue, options } = parseCookieString(value);
    const expiry = options['max-age']
      ? Date.now() + Number(options['max-age']) * 1000
      : Infinity;
    store.set(key, { value: cookieValue, expiry });
  },
  get() {
    return Array.from(store.entries())
      .filter(([, entry]) => Date.now() < entry.expiry)
      .map(([name, entry]) => `${name}=${entry.value}`)
      .join('; ');
  }
});
