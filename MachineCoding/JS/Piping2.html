Piping 2

Build a function that chains operations in sequence, passing the output of one function into the next.

Problem Summary

  • Take multiple functions as input.
  • Execute them in order.
  • Pass the previous result into the next function.
  • Return the final computed value.

Approach Template

// Suggested flow:
// 1) Create a function that accepts an initial value.
// 2) For each function in the pipeline:
//    - call the function with current value
//    - update the current value
// 3) Return the final result.
