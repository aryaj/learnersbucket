Method Chaining Calculator

This document shows how object methods can return this to support chainable operations.

The calculator object allows arithmetic expressions to be written in a fluent, chained style.

Implementation

function calculator() {
  return {
    total: 0,
    add: function (num) {
      this.total += num;
      return this;
    },
    subtract: function (num) {
      this.total -= num;
      return this;
    },
    multiply: function (num) {
      this.total *= num;
      return this;
    },
    divide: function (num) {
      this.total /= num;
      return this;
    },
    result: function () {
      return this.total;
    },
  };
}
