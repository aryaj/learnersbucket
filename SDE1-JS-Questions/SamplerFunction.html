Sampler Function

This page documents a higher-order function that invokes a callback only once every n calls.

The sampler keeps an internal counter and resets it after the callback runs.

Implementation

function samplerFunction(fn, count) {
  let counter = 0;
  return function () {
    if (++counter === count) {
      fn();
      counter = 0;
    }
  };
}
