Capture Focused Product

This example shows how to render a list of product cards, keep the view scrollable, and detect the products that are currently visible while the user scrolls.

Problem Summary

  • Create 27 product blocks with unique IDs.
  • Display them inside a scrollable panel.
  • Increase the card height so the list is easier to read.
  • Track which blocks are currently in the viewport while scrolling.

Implementation Idea

for (let i = 1; i <= 27; i++) {
  const block = document.createElement('div');
  block.id = String(i);
  block.className = 'blocks';
  block.textContent = `Product ${i}`;
  container.appendChild(block);
}
