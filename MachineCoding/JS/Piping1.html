Piping 1

Evaluate all function values inside a nested object by passing the same argument list everywhere, while preserving the original object shape.

Problem Summary

  • Input is a deeply nested object.
  • Some keys hold functions and some hold normal values.
  • Call each function with the provided args.
  • Replace each function with its computed result.
  • Return the transformed object with the same nesting.

Approach (Step By Step)

// STEP 1: Build a function Pipe(obj) that returns (...args) => result.
// STEP 2: Iterate all keys in the current object.
// STEP 3: If value is a function, execute value(...args) and store result.
// STEP 4: If value is a nested object, recurse: Pipe(value)(...args).
// STEP 5: If value is primitive/null, keep as-is.
// STEP 6: Return final object for this recursion level.
//
// Backtracking moment:
// After Pipe(value)(...args) finishes, control returns to parent level,
// and we assign that child result back to obj[key].

Recursion And Backtracking (Easy Memory Rule)

  • Recursion means: go deeper into child object.
  • Backtracking means: child call is done, now return to parent.
  • At backtracking time, parent receives child result and continues loop.
// Parent level
obj[key] = Pipe(child)(...args); // Go down
// child finished
// Backtracked here with computed child object

Dry Run Snapshot

// Input:
// {
//   a: {
//     b: (x, y, z) => x + y + z,
//     c: (x, y, z) => x + y - z
//   },
//   d: (x, y, z) => x - y - z
// }
// args = (1, 1, 1)
//
// Level 1: key a -> object -> recurse
//   Level 2: key b -> function -> 3
//   Level 2: key c -> function -> 1
//   return { b: 3, c: 1 }   (backtrack)
// Level 1: key d -> function -> -1
// Final:
// { a: { b: 3, c: 1 }, d: -1 }

Complexity

  • Time: O(n), where n = total keys visited in nested object.
  • Space: O(h), where h = recursion depth (call stack).
