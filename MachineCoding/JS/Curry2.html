Curry2

Build a sum function that accepts numbers over multiple calls. A call with one or more arguments should return another function; calling that function with no arguments should finish the chain and return the accumulated sum. This is a variadic currying pattern: each call can receive any number of values.

Problem Statement

Implement sum so that values can be provided in groups across calls, with an empty call marking the end of the chain.

sum(1, 2)(3, 4)() // 10
sum(5)()          // 5
sum()             // 0

Each non-empty call should return a function that accepts more values. The final empty call should return the sum of all values collected so far. Calling sum() immediately should return 0.

Approach (Step By Step)

  • Collect the first call: sum(...args) copies its arguments into the local storage array.
  • Handle an empty first call: when the initial argument list is empty, return 0.
  • Create the continuation function: otherwise, sum creates and returns temp, which closes over storage.
  • Check each continuation call: when temp receives no arguments, it reduces storage to a number; when it receives arguments, it returns temp again.
  • Important gap in this implementation: the non-empty continuation arguments are not appended to storage. As a result, later values are ignored rather than accumulated.

Closure and Dry Run

A closure lets temp keep access to the storage created by its original sum call, even after that call has returned. The current code keeps the initial values in that array, but does not add values received by later calls. 

sum(1, 2, 3, 4, 10)(20)()

1. Initial storage is [1, 2, 3, 4, 10].
2. temp(20) receives an argument, but returns temp without storing 20.
3. temp() receives no arguments and sums the unchanged storage.
4. Actual result: 20. Expected if every call accumulates: 40.

The first-call empty case does match the stated behavior: sum() returns 0. The continuation call also needs to append its non-empty arguments to storage for chained values to be included.

Complexity

  • Summing n stored values on the final empty call takes O(n) time.
  • Storing the supplied values takes O(n) space in total; the returned function retains that array through its closure.
