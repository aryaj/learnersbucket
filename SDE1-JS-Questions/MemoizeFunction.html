Memoize Function

Memoization is a performance optimization technique that caches the result of a function call so that repeating the same call returns the cached value instead of recomputing it.

How this implementation works

  1. Wrapping function: memoizeFunc(callbackFunc) returns a new function that remembers results.
  2. Cache storage: It keeps a plain object called cache to store previous results.
  3. Cache key: The wrapper creates a key from the call arguments using JSON.stringify(arguments).
  4. First call: If the key does not exist, it runs the original function and saves the output.
  5. Subsequent calls: If the same arguments are used again, it returns the cached result instantly.
Important: Memoization helps only for repeated calls with the same inputs. The first call still runs the full expensive computation.

Implementation

            
                function memoizeFunc(callbackFunc) {
                    const cache = {};

                    return function (...args) {
                        const key = JSON.stringify(args);

                        // If the computed result is already in cache, return it immediately.
                        if (key in cache) {
                        return cache[key];
                        }

                        // Otherwise, compute the result and store it for future calls.
                        const result = callbackFunc(...args);
                        cache[key] = result;
                        return result;
            };
            }

Why the UI can freeze

The slow function runs on the browser's main thread. While it is computing, the browser cannot process user input, render updates, or paint frames. If the computation takes longer than the frame budget (about 16ms at 60Hz), the page feels unresponsive.
