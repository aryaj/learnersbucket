Method Chaining

This page is prepared for a method chaining machine-coding question. The goal is to design an API where multiple method calls can be connected in a single fluent expression.

Problem Summary

  • Create an object/class with multiple operations.
  • Allow chained calls like obj.a().b().c().
  • Each chainable method should return the same instance.
  • Keep internal state consistent across each chained step.
  • Provide a final method to read the computed result/state.

Approach For Revision

  1. Define a class/object that stores current state (number, string, array, etc.).
  2. Implement operation methods (for example: add, subtract, multiply) that update state.
  3. Return this from each operation so the chain can continue.
  4. Add a terminal method (for example value()) to return the final output.
  5. Decide validation behavior for invalid inputs (ignore/throw/default).

Implementation Template

// Factory that returns a chainable API object.
function computeAmount(initialValue = 0) {
  let total = sanitizeNumber(initialValue);

  const api = {
    // Add lakh amount and return same object to continue chain.
    lakh(value = 0) {
      total += sanitizeNumber(value) * 100000;
      return api;
    },

    // Alias kept for compatibility with common spelling in problems.
    lacs(value = 0) {
      return api.lakh(value);
    },

    // Add crore amount and return same object.
    crore(value = 0) {
      total += sanitizeNumber(value) * 10000000;
      return api;
    },

    // Add thousand amount and return same object.
    thousand(value = 0) {
      total += sanitizeNumber(value) * 1000;
      return api;
    },

    // Read final amount (terminal method).
    value() {
      return total;
    },
  };

  return api;
}

function sanitizeNumber(input) {
  const parsed = Number(input);
  if (!Number.isFinite(parsed)) {
    throw new Error('Amount must be a finite number');
  }
  return parsed;
}
