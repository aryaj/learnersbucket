Reduce Function Example

This page demonstrates the JavaScript Array.prototype.reduce() method with three common use cases:

  • Sum of numbers
  • Flattening nested arrays
  • Counting item occurrences

Reduce usage

const numbers = [10, 20, 30];
            const sum = numbers.reduce((acc, value) => acc + value, 0);

            const flat = nested.reduce((acc, value) => acc.concat(value), []);
