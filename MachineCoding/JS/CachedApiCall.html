Cached API Call

This example demonstrates how to wrap fetch with a simple cache so repeated requests within a given time window return the cached result instead of hitting the network again.

Problem Summary

  • Accept a TTL value in milliseconds.
  • Create a reusable wrapper that can be called multiple times.
  • Use a cache key based on the URL and request config.
  • If a fresh entry exists and is still valid, return the cached value.
  • Otherwise, make a network request and store the response.

Implementation Idea

function createCachedApiCall(ttl) {
  const cache = new Map();

  return async function(url, config = {}) {
    const key = `${url}|${JSON.stringify(config)}`;
    const now = Date.now();
    const entry = cache.get(key);

    if (entry && now < entry.expiry) {
      return { data: entry.value, source: 'cache' };
    }

    const response = await fetch(url, config);
    const data = await response.json();

    cache.set(key, { value: data, expiry: now + ttl });
    return { data, source: 'network' };
  };
}
