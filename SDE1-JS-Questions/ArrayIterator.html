Array Iterator

This example shows how to build a simple iterator helper for arrays. The iterator exposes next() and done() methods so you can manually traverse values.

How it works

The iterator stores an internal index and returns the next element on each call. Once the array is exhausted, next() returns null. The done() method checks whether another item is available.

Implementation

function iteratorHelper(arr) {
  let index = 0;
  return {
    next: function () {
      const value = arr[index++];
      return value !== undefined ? value : null;
    },
    done: function () {
      return index >= arr.length;
    },
  };
}
