Polyfill: getElementByClassname

Implement a custom version of class-based element search without using document.getElementsByClassName directly.

Problem Summary

  • Input: class name string.
  • Output: all DOM elements that contain that class.
  • Support multi-class elements (space-separated class attribute).
  • Do not use the native getElementsByClassName API.
  • Return consistent array-like results for easy testing.

Approach (Step By Step)

// STEP 1: Start from the given root element.
// STEP 2: Check whether the current node contains the target class.
// STEP 3: If yes, add the node to the result array.
// STEP 4: Recurse into each child element.
// STEP 5: Merge all child results into the current result.
// STEP 6: Return the full result array.
//
// Why this works:
// A DFS traversal visits every descendant node exactly once.
// Each node is checked independently, so the logic is simple and clear.
//
// Complexity:
// Time: O(n) where n is number of DOM nodes visited.
// Space: O(k) where k is number of matched nodes.

Dry Run

// Suppose we search for class "a" in the sample tree.
// root (has a) -> match
// child-1 (no a) -> skip
// grandchild (has a) -> match
// child-2 (no a) -> skip
// grandchild-2 (has a) -> match
// Result: [root, grandchild, grandchild-2]
