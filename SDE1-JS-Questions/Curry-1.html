Curry Function Example

This document explains a simple curry-style accumulator using JavaScript closures.

The returned function retains a private sum value, updates it on every call, and returns the accumulated total.

How it works

  1. Closure: curry() creates a private variable, sum.
  2. Returned function: Each invocation has access to that private variable.
  3. Accumulation: Calling the returned function adds its argument to sum.
  4. Default value: If no argument is provided, the value defaults to 0.

Implementation

function curry() {
  let sum = 0;
  return (val = 0) => {
    sum += val;
    return sum;
  };
}
