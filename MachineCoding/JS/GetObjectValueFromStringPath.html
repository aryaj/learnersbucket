Get Object Value From String Path

This question is about reading nested values from an object using a string path like "user.profile.name" or "items[0].title".

Problem Summary

  • Accept an object and a path string.
  • Return value at the given path if it exists.
  • Support dot notation and bracket notation.
  • Return fallback/default value when path does not exist.
  • Handle null/undefined safely without crashing.

Approach Template

// Suggested flow:
      // 1) Normalize bracket notation into dot notation.
      // 2) Split the path into a list of keys.
      // 3) Walk the object one key at a time.
      // 4) Stop immediately if a null/undefined value is encountered.
      // 5) Return the resolved value or the fallback/default value.

Implementation Notes

// API shape:
      // getObjectValueFromStringPath(obj, path, defaultValue)
      //
      // - obj: source object or array
      // - path: string like "user.profile.name" or "items[0].title"
      // - defaultValue: used when the path cannot be resolved
