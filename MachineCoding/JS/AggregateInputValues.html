Understanding the Problem

The objective is to take flat input names like foo.bat, foo.bar.baz, and fizz, and merge them into a single nested JavaScript object. 

Input shape:
foo.bat = "1"
foo.bar.baz = "2"
fizz = "3"

Output:
{
  foo: {
    bat: "1",
    bar: {
      baz: "2"
    }
  },
  fizz: "3"
}
This is a path-building problem: each dot-separated key is a route in the object.

Why This Works

  1. Split each key by . into path segments.
  2. Begin from the root object.
  3. Traverse step by step using each segment.
  4. Create a nested object whenever a parent segment is missing.
  5. Assign the actual value only at the last segment.

Step-by-Step Example

// key = 'foo.bar.baz'
// split => ['foo', 'bar', 'baz']

result = {}

1) result['foo'] = {}
2) result['foo']['bar'] = {}
3) result['foo']['bar']['baz'] = value

Final:
{
  foo: {
    bar: {
      baz: value
    }
  }
}

Optimized Solution

function aggregateInputValues(entries) {
  const result = {};

  for (const { key, value } of entries) {
    const trimmedValue = value.trim();
    if (!trimmedValue) continue;

    const path = key.split('.');
    let current = result;

    for (let i = 0; i < path.length; i++) {
      const segment = path[i];
      const isLastSegment = i === path.length - 1;

      if (isLastSegment) {
        current[segment] = trimmedValue;
      } else {
        if (!current[segment] || typeof current[segment] !== 'object') {
          current[segment] = {};
        }
        current = current[segment];
      }
    }
  }

  return result;
}

Complexity

  • Time complexity: O(n * k), where n is the number of fields and k is the path depth.
  • Space complexity: O(n * k) because the nested object is constructed in memory.
