Debounce Example

This page explains how debounce delays function execution until after a quiet period.

Debounce is useful for rate-limiting repeated events such as clicks, input, or scroll events.

Implementation

function debounce(fn, delay) {
  let timerId;

  return function (...args) {
    const context = this;
    clearTimeout(timerId);
    timerId = setTimeout(() => fn.apply(context, args), delay);
  };
}
