Animate Progress Bar

This page is prepared for the progress bar animation machine-coding question. Implement the animation logic in the script section when you solve it.

Problem Summary

  • Create a progress bar UI with a track and fill element.
  • Animate fill width from 0% to target value.
  • Support configurable speed/duration.
  • Handle restart/reset behavior cleanly.
  • Optionally support pause/resume for advanced cases.

Solution Approach (Queue Based)

// 1) Keep a queue (array) of pending progress-bar jobs.
      // 2) On each Add click, push one job to queue.
      // 3) If processor is idle, start processNext().
      // 4) processNext() picks one job, renders one bar, animates to 100%.
      // 5) On transitionend, process next queued job.
      // 6) Reset clears queue, container, and invalidates active run token.
