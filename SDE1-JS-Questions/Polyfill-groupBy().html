Polyfill - groupBy

This example implements a reusable groupBy helper using Array.prototype.reduce. The function groups array items by a key computed from each element.

How it works

For each item, the function derives a group key using either a callback or a property name. It then appends the item into the corresponding bucket inside the accumulator object.

Implementation

function groupBy(arr, keyFinder) {
  return arr.reduce((result, item) => {
    const key = typeof keyFinder === 'function' ? keyFinder(item) : item[keyFinder];
    if (!result[key]) {
      result[key] = [];
    }
    result[key].push(item);
    return result;
  }, {});
}
