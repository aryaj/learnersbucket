FeatureFlag Component (React)

Implement a Feature Flag component and demonstrate its usage in this React/machhinecoding project.

Goal

  • Create a small React component that conditionally renders content based on a feature flag.
  • Support both a simple boolean flag and a dynamic predicate (function) to decide whether a feature is enabled.
  • Provide example usage and quick test instructions.

Requirements

  1. The component should accept a `flag` prop (boolean or string key) or a predicate function.
  2. Allow rendering children when the flag is enabled, otherwise render fallback children or nothing.
  3. Document how to wire the component to a runtime feature flag source (context, config, or environment variable).
