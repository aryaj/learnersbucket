Curry4

Build a curried sum function that keeps accumulating numbers across repeated calls. The important twist is that the returned function can behave like a number because its prototype exposes valueOf.

Problem Statement

Create a function add(...args) that returns a callable helper. Each helper call can receive more arguments, and the result can be read either by calling .value() or by using the helper in a numeric expression where JavaScript implicitly calls valueOf(). 

add(1)(2)(3).value()  // 6
add(1, 2, 3).value()  // 6
add(1)(2) + 3         // 6

Approach (Step By Step)

  • Collect values: each call pushes incoming arguments into a closure-backed storage array.
  • Return a callable function: the helper keeps returning itself so more numbers can be added in the same chained flow.
  • Create a terminal value: define valueOf so the helper converts into a number whenever JS needs a primitive.
  • Expose a named getter: assign helper.value = helper.valueOf so the API supports .value() as well.
  • Use implicit conversion: add(1)(2) + 3 works because JavaScript calls valueOf() automatically.

Closure and Dry Run

The returned helper closes over storage. That means all intermediate calls share the same array, so each argument is added to the same running total instead of resetting on every call. 

add(1)(2)(3).value()

1. add(1) creates storage = [1], returns helper
2. helper(2) pushes 2 => [1, 2]
3. helper(3) pushes 3 => [1, 2, 3]
4. value() calls valueOf() and reduces [1, 2, 3] to 6

Complexity

  • Each call appends values to the storage array in O(1) time per argument.
  • The final reduction is O(n), where n is the total number of stored values.
