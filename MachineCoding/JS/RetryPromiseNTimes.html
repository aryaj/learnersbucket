Retry Promise N Times

This page is prepared for implementing retry logic where a promise-returning function is attempted up to a maximum number of retries before failing.

Problem Summary

  • Accept a promise-producing function and retry count n.
  • Retry only when promise rejects.
  • Stop immediately if the promise resolves.
  • Reject with final error after all retries are exhausted.
  • Optionally support delay/backoff between attempts.

Solution Approach

// 1) Validate inputs (fn should be function, retries should be >= 0).
    // 2) Attempt fn() once.
    // 3) If resolved, return immediately.
    // 4) If rejected and retries remain, call recursively with retries - 1.
    // 5) If retries are exhausted, reject with finalError (or last caught error).
    // 6) Total attempts = retries + 1 (initial attempt + retry attempts).

Implementation Notes

// API shape:
    // retryPromiseNTimes(fn, retries, finalError?) => Promise
    //
    // - fn: function returning a Promise
    // - retries: number of retry attempts after first failure
    // - finalError: optional error/message returned after all attempts fail
